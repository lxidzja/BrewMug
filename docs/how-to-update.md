# Як оновити сайт (для власника кав'ярні)

Усе, що гість бачить на сайті — меню, години, адреса, телефон — лежить у кількох текстових файлах. Змінити їх можна без програміста, але потрібно **перезібрати сайт** (команда нижче).

---

## Години роботи, адреса, телефон

Файл: **`src/data/site.yaml`**

Кожен рядок — «ключ: значення». Не змінюйте відступи зліва — вони важливі.

```yaml
address:
  street: вул. Кавова, 12      ← адреса
  city: Київ
  postalCode: "01000"
  note: 3 хвилини від метро «Подільська»

phone: "+380441234567"         ← без пробілів, для кнопки «подзвонити»
phoneDisplay: "+380 44 123 45 67"  ← як показувати на сайті
email: hello@brewmug.ua
```

**Години:**

```yaml
hours:
  - days: [1, 2, 3, 4]   # 0 = неділя, 1 = понеділок … 6 = субота
    open: "08:00"
    close: "22:00"
```

- `days` — список днів у квадратних дужках через кому.
- `close` може бути більшим за 24, якщо кав'ярня працює після півночі: `"26:00"` = 2:00 ранку.
- **Вихідний день (свято):** додайте у `closures`:

```yaml
closures:
  - date: "2026-12-25"
    reason: вихідний
```

Після зміни год́ин оновлюються одночасно: шапка, головна, футер, контакти й вільні години в бронюванні.

## Меню

Файли: `src/data/menu/kava.yaml`, `chai.yaml`, `deserty.yaml`, `sneky.yaml`

Одна позиція виглядає так:

```yaml
  - slug: flat-white          ← унікальна назва латиницею (не змінюйте без потреби)
    name: Флет вайт           ← назва на сайті
    price: 78                 ← ціна гривнями, лише число
    description: Подвійне еспресо й шовковиста молочна пінка.
    illo: flat                ← картинка (див. нижче)
    tag: hit                  ← необов'язково: hit (хіт) або new (новинка)
```

**Додати позицію** — скопіюйте блок і змініть поля.

**Прибрати з меню** — видаліть блок цілком (рядки з `- slug:` до кінця опису).

**Змінити ціну** — змініть число біля `price`. Нічого більше не треба.

**Картинки:** доступні назви — `espresso, flat, cappuccino, latte, filter, citrus, tea, cocoa, buckthorn, matcha, icedlatte, lemonade, coldbrew, mojito, honeycake, cheesecake, brownie, tart, croissant, syrniki, sandwich, toast, waffle, granola, eggs`. Якщо потрібна нова — напишіть розробнику.

**Дата оновлення:** змініть `updatedAt: 2026-11-01` — ця дата показується на сторінці меню.

## Після будь-якої зміни

```bash
npm run build          # перевірить дані й збере сайт
```

Якщо команда видала помилку — у тексті буде вказано файл і поле, яке треба виправити (наприклад, «ціна має бути цілим числом більше нуля»). Нічого не публікується, поки помилка не виправлена.

---

## Перевірка

- ✅ Не менше 15 позицій і 4 категорії (вимога замовника).
- ✅ Дата оновлення меню стоїть.
- ✅ Заглушки (`placeholder: true`) прибрані — інакше сайт не збереться.

---

## Якщо щось не виходить

Поверніть файл до попереднього стану (команда `git checkout -- src/data/`) і напишіть розробнику, що саме хотіли змінити.
